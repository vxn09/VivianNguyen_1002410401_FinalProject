# VivianNguyen_1002410401_FinalProject
Vivian Nguyen #1002410401 Bioinformatics Final Project

Project title: Analysis of Host Gene Expression Changes to Helicobacter pylori infections in Gastric Epithelial Cells 

Overview: This project will evaluate and analyze how _Helicobacter pylori_ impacts gene expression in gastric epithelial cells of human hosts. Public RNA-Seq data of uninfected versus infected gastric epithelial cells of the GES-1 cell line will be analyzed. Genes that are the most upregulated or downregulated will be identified and investigated to determine biological functions and how it relates to our main research question. 

Research Question: How does _Helicobacter pylori_ infection in human host cells affect or alter gene expression?

Dataset Used: NCBI:GEO Gastric epithelial cells infected with Helicobacter pylori for 24 hours, with accession ID GSE295523 

Tools and Packages: Python, R, DESeq2

Repository Contents: ai_usage.md file, Colab notebook with all the code for the project.
